# Build in Public — 3 posts courts

*Un par moment du voyage. Format court, une idée par post, une image par post.
Publier sur X et LinkedIn (LinkedIn : garder les sauts de ligne, ils portent).*

```

de mesures encore presque vide.

C'est le carnet qui compte. On part le remplir.

## Post 2 — Arrivée à Macaíba

**Quand publier :** arrivée, installation du poste de travail.

```
Arrivé à Macaíba (RN, Brésil).

Première installation du poste nomade : un MacBook sous Linux Mint, trois écrans,
un dock Thunderbolt 3. Tout tient dans un sac qu'on porte à une main.

L'idée n'est pas d'être confortable. C'est de pouvoir travailler là où le terrain

Premières prises de vues cette semaine.

**Visuel :** le poste monté, trois écrans allumés, une fenêtre ouverte sur la
lumière brésilienne.

## Règles pour ces trois posts

1. **Un post, une idée.** Pas de récapitulatif, pas de « par ailleurs ».
2. **Une image réelle.** Une photo de matériel vaut dix schémas propres.
3. **Dire l'échec avant qu'on le demande.** C'est ce qui donne du crédit au reste.
4. **Toujours un lien.** Même discret : le post doit pouvoir mener quelque part.
5. **Répondre.** Un post sans réponse dans l'heure est un post qui n'a pas eu lieu.
